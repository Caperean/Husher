# Husher
Husher is a light app to check that file in indicated by user path is identical in hash.

## Algorithms
Husher can use following hashing algorithms:
adler32
blake2s
blake2b
blake3
crc32
crc64
gost
keccak256
keccak512
md5
ripemd160
sha1
sha3_224
sha3_256
sha3_512
sha224
sha256
sha384
sha512
sha512_224
sha512_256
streebog
tiger
whirlpool
xxhash3
xxhash32
xxhash64
